# 📚 Obook

## 🚀 Project Overview
**Obook** is a web application built with **PHP** that offers a comprehensive platform for reading books. It supports both **audiobooks** and **e-books**, allowing users to upload their own books, track their favorite reads, and keep a history of their reading progress.

The website also includes an **Admin Dashboard** for managing all necessary information efficiently, and a **Community Page** where users can freely post and share content.

## 🌟 Key Features
- 🎧 Listen to **audiobooks** and 📖 read **e-books**
- ➕ Upload new books to the platform
- ⭐ Track and follow favorite books
- 🕒 Store and manage users’ reading history
- 🔐 Admin dashboard to manage users, books, and community content
- 🌐 Community page for user-generated posts and interactions

## 🛠 Technology Stack
- Backend & Frontend: **PHP**
- Database: **MySQL** or compatible relational database
- Frontend: **HTML**, **CSS**, **JavaScript**

- Register and log in to read books and save your reading progress
